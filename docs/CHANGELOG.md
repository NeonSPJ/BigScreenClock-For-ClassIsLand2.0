# 更新日志

> 版本规则：四位版本号。第 3 位 = 问题修复；第 2 位 = 新功能；第 1 位 = 重大功能更新（如适配多平台）；末位非 0 表示测试版。

## 1.0.1.2（测试版 · 2026-08-29）

> 1.0.0.0 规划的功能已全部上线，含此前因 bug 暂缓的「课程进度条」。

### ✨ 新功能

- **V2 音量检测算法**：平滑（EMA）+ 迟滞 + 持续判定，咳嗽、喷嚏等瞬态噪音不再误计数
- **「段模式」吵闹计数**：
  - 一段噪音累计满「起算底线」（默认 1 秒，可调 0.5~5 秒）才记一次，无冷却
  - 「回落窗口」（默认 5 秒，可调 0~15 秒）内短暂安静不断段，重新吵起并成一次
  - 按段内「一般 / 吵闹」时长占比归属：吵闹占一半及以上记「吵闹」，否则记「一般」
  - 实时「正在记录」提示（一般黄 / 吵闹红）
- **课程进度条**（底部双色条）：上课显示本课进度、课间显示当前休息进度；已进行深色 / 未进行浅色；颜色可调
- **HSV 颜色选择器**：背景 / 字体 / 强调色 / 进度条颜色改为取色器调整（点击色块弹出完整 HSV 面板，也可直接填 hex）
- **RMS 阈值对数滑块**：0.001~1.000，拖动滑块或直接填数字，双向联动
- **上课初期保护可调**：上课后前 0~10 分钟不计数（默认 3 分钟，可关闭）
- **调试日志**：输出 NoiseDebugLog CSV，用于收集真实数据校准阈值
- 时钟字号可调（60~400px）；设置页实时预览

### 🐛 修复

- 调整外观颜色后需重启 ClassIsland 才生效 → 进入全屏时自动刷新颜色绑定
- 颜色选择器控件偏小、与宽设置界面不协调 → 色块移至每行最右并放大
- 课程事件订阅泄漏（P0）
- 课程进度与时间显示不匹配
- 加入进度条后无法全屏（任务栏残留）

### 🔧 调整

- 音量等级表情：安静 🙂、良好 🤫（原为 🤫 / 🙂）
