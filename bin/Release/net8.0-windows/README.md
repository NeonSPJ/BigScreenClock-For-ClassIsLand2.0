# 大屏时钟 (BigScreenClock)

ClassIsland 插件 —— 自动全屏显示当前时间、教室分贝值和课程信息。

## 功能

- 🕐 **全屏时钟**：精确到秒的大字体时间，适配教室大屏幕，字号可调
- 🎤 **教室音量检测**：实时麦克风音量，五档显示（安静/良好/一般/吵闹/嘈杂），麦克风休眠后自动重连
- 📋 **课程时间**：显示当前课程名称和起止时间，课间显示下节课程
- 📊 **吵闹统计（段模式）**：按课程分段统计「一般 / 吵闹」次数；一段噪音累计满 1 秒记一次、无冷却，回落窗口内短暂停顿不断段；上课初期保护可调
- 📈 **课程进度条**：上课显示本课进度、课间显示休息进度，已进行深色 / 未进行浅色
- 🎨 **HSV 颜色选择器**：背景 / 字体 / 强调色 / 进度条颜色取色器调整
- 🛡️ **防休眠/防屏保**：全屏期间阻止系统进入休眠和屏幕保护

## 安装

大屏时钟现已上架 ClassIsland 插件市场，可在「应用设置 → 插件 → 插件市场」中搜索并直接安装。

> 提示：插件市场更新存在延迟。如需获取最新版本，可在大屏时钟全屏界面右上角连击日期文字 7 次，在弹出的「关于」窗口中点击链接前往 GitHub 仓库下载。

手动安装：

1. ClassIsland → 应用设置 → 插件 → 「刷新」旁的「...」→ 从本地安装
2. 重启 ClassIsland
3. 在「设置 → 大屏时钟」中进行配置
