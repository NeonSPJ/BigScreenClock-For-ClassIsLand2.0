# 大屏时钟 (BigScreenClock)

ClassIsland 插件 —— 自动全屏显示当前时间、教室分贝值和课程信息。

## 功能

- 🕐 **全屏时钟**：精确到秒的大字体时间，适配教室大屏幕
- 🎤 **教室分贝检测**：实时麦克风音量，五档显示（安静/良好/一般/吵闹/嘈杂）
- 📋 **课程时间**：显示当前课程名称和起止时间，课间显示下节课程
- 📊 **吵闹统计**：按课程分段统计吵闹次数，课间自动总结
- 🔄 **自动触发**：检测到目标课程自动全屏，连堂不退出
- ⌨️ **快捷退出**：Esc / F11 / 退出按钮

## 安装

1. 将 `.cipx` 文件复制到 ClassIsland 插件目录（`data/Plugins/`）
2. 重启 ClassIsland 或在插件管理中加载
3. 在 设置 → 插件 → 大屏时钟 中配置

## 配置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 触发课程 | 从课表选择 | 下拉框选择，可添加多个 |
| 噪音阈值 | RMS 值 | 四级可调，影响等级判定 |
| 外观颜色 | 黑底白字绿条 | 背景/字体/强调色可调 |

## 技术栈

ClassIsland Plugin SDK v2.1.0.1 + NAudio + Avalonia
