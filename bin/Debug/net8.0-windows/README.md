# 大屏时钟 (BigScreenClock)

ClassIsland 插件 —— 自动全屏显示当前时间、教室分贝值和课程信息。

## 功能

- 🕐 **全屏时钟**：精确到秒的大字体时间，适配教室大屏幕，字号可调
- 🎤 **教室RMS检测**：实时麦克风音量，五档显示（安静/良好/一般/吵闹/嘈杂），麦克风休眠后自动重连
- 📋 **课程时间**：显示当前课程名称和起止时间，课间显示下节课程
- 📊 **吵闹统计**：按课程分段统计「一般」和「吵闹」次数，支持冷却时间（默认 60 秒）和课前 3 分钟不记录，课间自动总结
- 🛡️ **防休眠/防屏保**：全屏期间阻止系统进入休眠和屏幕保护

## 安装

1. ClassIsland2.0 → 应用设置 → 插件 → “刷新”旁边的“...” → 从本地安装
2. 重启 ClassIsland
3. 在 设置 → 大屏时钟 中进行设置
