# 大屏时钟 (BigScreenClock)

ClassIsland 插件 —— 自动全屏显示当前时间、教室分贝值和课程信息。

## 功能

- 🕐 **全屏时钟**：精确到秒的大字体时间，适配教室大屏幕，字号可调
- 🎤 **教室分贝检测**：实时麦克风音量，五档显示（安静/良好/一般/吵闹/嘈杂），麦克风休眠后自动重连
- 📋 **课程时间**：显示当前课程名称和起止时间，课间显示下节课程
- 📊 **吵闹统计**：按课程分段统计「一般」和「吵闹」次数，支持冷却时间（默认 60 秒）和课前 3 分钟不记录，课间自动总结
- 🔄 **自动触发**：检测到目标课程自动全屏，连堂不退出
- 🛡️ **防休眠/防屏保**：全屏期间阻止系统进入休眠和屏幕保护
- 🖱️ **自动隐藏光标**：鼠标 10 秒无操作自动隐藏
- 📝 **规则说明**：全屏界面底部显示记录规则与免责声明
- ⌨️ **快捷退出**：Esc / F11 / 退出按钮

## 配置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 触发课程 | 从课表选择 | 下拉框选择，可添加多个 |
| 噪音阈值 | RMS 值 | 四级可调，影响等级判定 |
| 吵闹冷却 | 60 秒 | 两次计数之间的最小间隔 |
| 课前 3 分钟 | 开启 | 上课前 3 分钟内不计数 |
| 外观颜色 | 黑底白字绿条 | 背景/字体/强调色可调 |
| 时钟字号 | 180px | 60–400 可调，实时预览 |

## 技术栈

ClassIsland Plugin SDK v2.1.0.1 + NAudio + Avalonia
